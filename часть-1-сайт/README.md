# Сайт-магазин филаментов для 3D-печати

Статический сайт (HTML, CSS, JavaScript) — без сборки и серверной части.

## Структура

- `index.html` — главная
- `shop.html` — каталог
- `product.html` — страница товара
- `compare.html` — лаборатория материалов
- `about.html` — о бренде
- `support.html` — поддержка
- `cart.html` — корзина и оформление заказа (демо)
- `css/style.css` — стили
- `js/data.js` — все данные: бренд, контакты, валюты, коллекции, товары
- `js/app.js` — логика: шапка, корзина, поиск, отрисовка страниц
- `assets/` — картинки, которые использует сайт
- `originals/` — исходные фотографии в полном размере (сайтом не используются)

## Как посмотреть локально

В Windows: запустить в папке `powershell -ExecutionPolicy Bypass -File serve.ps1` и открыть http://localhost:8080

## Важно

Это шаблон. Название бренда, цены, цифры, отзывы и условия доставки — заглушки. Оплата и формы работают в демо-режиме.
